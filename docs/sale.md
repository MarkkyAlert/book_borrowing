# โพสต์ขาย — สำหรับกลุ่ม Developer / Freelance

---

ระบบยืมคืนหนังสือ — PHP Source Code สำหรับเอาไปต่อยอด

---

ระบบนี้ไม่ใช่โค้ดตัวอย่างจาก tutorial
เขียนแยก layer ชัดเจน มี business logic จริง ผ่าน test จริง
ถ้าคุณเป็น dev ที่กำลังหา base system ไว้ปรับส่งลูกค้า หรืออยากได้ codebase ที่อ่านรู้เรื่องไว้ศึกษา — ลองอ่านต่อครับ

---

▸ โครงสร้างเชิงเทคนิค

- Pure PHP 8.1+ / MySQL / Apache — ไม่พึ่ง framework
- แยก layer: Controller → Service → Repository → View
- Business logic อยู่ใน Service ไม่ปนกับ View
- Repository ใช้ PDO prepared statements ทั้งหมด
- ทุกไฟล์มี comment อธิบายเชิงระบบ — ทำไมเขียนแบบนี้ จุดไหนห้ามแก้ จุดไหนต่อยอดได้

---

▸ ฟีเจอร์หลักของระบบ

ระบบยืมคืนหนังสือที่ครอบคลุมงานห้องสมุดตั้งแต่ต้นจนจบ
ตั้งแต่สมัครสมาชิก → จองหนังสือ → ยืม → คืน → คำนวณค่าปรับ → ชำระเงิน
รองรับ 3 role (Admin, Staff, Member) แยกสิทธิ์ชัดเจนผ่าน middleware

📚 Feature Overview

- ระบบยืม–คืนหนังสือ (บันทึกวันยืม/กำหนดคืน/วันคืนจริง)
- ระบบจองหนังสือ (หมดอายุอัตโนมัติ + lazy expiration)
- ระบบคำนวณค่าปรับอัตโนมัติ (ตามจำนวนวันเกิน x อัตราต่อวัน)
- ระบบชำระค่าปรับ (บันทึกยอด + ประวัติการชำระ)
- ระบบจัดการหนังสือ + หมวดหมู่ (CRUD + upload รูปปก)
- ระบบจัดการสมาชิก (CRUD + แบ่ง role)
- Import ข้อมูลจาก CSV (หนังสือ + สมาชิก, รองรับ BOM + upsert)
- Dashboard สถิติ + รายงานค่าปรับ + Export PDF
- บัตรสมาชิก + ป้ายหนังสือ (print ได้)
- ค้นหา + กรองตามหมวดหมู่ + pagination
- Responsive — ใช้ได้ทั้ง desktop และมือถือ

▸ สิทธิ์ตาม Role

📌 Admin (ผู้ดูแลระบบ)

ทำได้ทุกอย่างที่ Staff ทำได้ รวมถึง:
- ตั้งค่าระบบ (ชื่อองค์กร, สีธีม, จำนวนวันยืม, ค่าปรับต่อวัน, โควตายืม)
- ดูรายงานสถิติ + Export PDF
- จัดการ role ของสมาชิก (เลื่อนเป็น staff / ลดเป็น member)
- ลบสมาชิก (มี FK safety — ลบไม่ได้ถ้ามีประวัติยืม)

📌 Staff (เจ้าหน้าที่)

งานประจำวันของห้องสมุด:
- บันทึกการยืม–คืนหนังสือ
- อนุมัติ/ยกเลิกการจอง
- เพิ่ม/แก้ไข/ลบ หนังสือ + หมวดหมู่
- เพิ่ม/แก้ไข สมาชิก + พิมพ์บัตรสมาชิก
- Import ข้อมูลจาก CSV (หนังสือ + สมาชิก)
- ดูรายการค่าปรับค้างชำระ + บันทึกการชำระ
- พิมพ์ป้ายหนังสือ (label)
- ดู Dashboard สถิติ

📌 Member (สมาชิก)

เข้าใช้งานผ่านหน้าเว็บ:
- สมัครสมาชิก + Login/Logout
- ดูรายการหนังสือ + ค้นหา + กรองตามหมวดหมู่
- จองหนังสือ (กดจองจากหน้ารายละเอียดหนังสือ)
- ยกเลิกการจองของตัวเอง
- ดูประวัติการยืม + สถานะ (กำลังยืม / คืนแล้ว / เลยกำหนด)
- ดูประวัติการจอง + สถานะ (รอดำเนินการ / สำเร็จ / ยกเลิก / หมดอายุ)
- แก้ไขโปรไฟล์ + เปลี่ยนรหัสผ่าน

👤 Guest (ไม่ login)

- ดูหน้าแรก + รายการหนังสือ + ค้นหาได้
- ดูรายละเอียดหนังสือได้
- สมัครสมาชิกได้
- จอง/ยืม/ดูประวัติ → ต้อง login ก่อน

---

▸ หมายเหตุเชิงเทคนิค

การแยก role ทำผ่าน middleware 3 ระดับ:
- requireLogin() — ต้อง login ก่อนถึงเข้าหน้านี้ได้
- requireStaff() — ต้องเป็น staff หรือ admin
- requireAdmin() — ต้องเป็น admin เท่านั้น

Guard เหล่านี้ถูกเรียกที่ต้นไฟล์ทุกหน้า — ถ้าอยากเพิ่ม role ใหม่ (เช่น librarian)
แก้แค่ functions.php + เพิ่ม guard ใหม่ ไม่ต้องแก้ business logic

▸ คุณภาพระบบ

- Transaction + SELECT FOR UPDATE กัน race condition
- Idempotency key กันกดซ้ำ (ยืม/คืน/จ่าย/ยกเลิก)
- PRG pattern ทุก form — กด refresh ไม่ submit ซ้ำ
- SQL Injection: PDO prepared statements + EMULATE_PREPARES=false
- XSS: htmlspecialchars ทุก output
- CSRF: per-session token ทุก POST
- Brute force: rate limiting (login, register, forgot password)
- DB constraints: CHECK stock >= 0, UNIQUE กัน duplicate, FK cascade
- Session: regenerate ID หลัง login, HttpOnly + SameSite cookie

ผ่านการทดสอบ 20 หมวด 200+ test cases — ทั้ง logic test และ HTTP-level test

▸ เหมาะกับ

- Freelance ที่รับงานระบบห้องสมุด — ซื้อไปปรับ ส่งลูกค้าได้เลย
- Dev ที่อยากได้ base system ไว้ต่อยอด — โครงสร้างพร้อม เพิ่มฟีเจอร์ได้ทันที
- คนที่อยากศึกษา PHP แบบ production — ไม่ใช่โค้ด hello world

▸ ไม่เหมาะกับ

- ต้องการระบบ enterprise หลายสาขา — ระบบนี้ออกแบบสำหรับที่เดียว
- ต้องการ SaaS multi-tenant — ไม่ได้ออกแบบไว้
- ต้องการ mobile app — เป็น web app อย่างเดียว
