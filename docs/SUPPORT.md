# 📋 นโยบายการซัพพอร์ต — ระบบยืมคืนหนังสือ

## 🎯 1. ภาพรวมการซัพพอร์ต

สวัสดีครับ ขอบคุณที่เลือกซื้อโค้ดชุดนี้ 🙏

โค้ดชุดนี้เป็น **PHP Template สำหรับระบบยืมคืนหนังสือ** ที่ออกแบบมาเพื่อ:
- ใช้เรียนรู้ PHP + Backend
- ส่งงาน / ส่ง Project
- เดโมให้ลูกค้าหรืออาจารย์ดู
- ใช้งานจริงในห้องสมุดหรือร้านขนาดเล็ก

การซัพพอร์ตมีไว้เพื่อ **ช่วยให้คุณเริ่มต้นใช้งานได้** ไม่ติดปัญหาตั้งแต่ขั้นตอนแรก
และเพื่อให้คุณเข้าใจโครงสร้างของโค้ดจนสามารถนำไปต่อยอดหรือปรับแต่งได้ด้วยตัวเอง

> 💡 ผู้ขายเป็นนักพัฒนาบุคคล ไม่ใช่บริษัทที่มีทีม support 24 ชั่วโมง
> ดังนั้นการซัพพอร์ตจะเน้น "ช่วยให้เริ่มต้นได้" และ "ตอบคำถามที่อยู่ในขอบเขต"

## ✅ 2. สิ่งที่ซัพพอร์ตให้

### ติดตั้งและเริ่มต้น
- แนะนำวิธีติดตั้ง XAMPP + วางโค้ด + รัน `install.php`
- ช่วยแก้ปัญหาตอนติดตั้ง เช่น เชื่อมต่อ database ไม่ได้, Apache ไม่ start
- อธิบายวิธีตั้งค่าไฟล์ `.env`

### อธิบายโครงสร้างและการทำงาน
- อธิบายว่าโฟลเดอร์ไหนทำหน้าที่อะไร
- อธิบาย flow การทำงานหลัก เช่น login, ยืม, คืน, จอง
- อธิบายว่าไฟล์ไหนแก้ได้ / ไฟล์ไหนไม่ควรแก้

### แก้ไข bug ของโค้ดต้นฉบับ
- ถ้าโค้ด **ต้นฉบับที่ยังไม่ถูกแก้ไข** มี error หรือทำงานไม่ถูกต้อง → แจ้งมาได้เลย จะรีบแก้ไขให้
- รวมถึงปัญหาที่เกิดจากการตั้งค่าเริ่มต้นที่ไม่ครบ

### ตอบคำถามทั่วไป
- "แก้ค่าปรับต่อวันตรงไหน?"
- "เพิ่มจำนวนวันยืมยังไง?"
- "ทำไม login ไม่ได้?"
- คำถามลักษณะนี้ ถามได้เลย ยินดีตอบครับ

## ❌ 3. สิ่งที่ไม่อยู่ในขอบเขตการซัพพอร์ต

พูดตรงๆ ด้วยความเคารพนะครับ — สิ่งเหล่านี้ **อยู่นอกเหนือขอบเขต** ของการซัพพอร์ต:

### ❌ เขียนฟีเจอร์ใหม่ให้
- เช่น "ช่วยเพิ่มระบบแชท", "ช่วยเพิ่มระบบแจ้งเตือน Line"
- โค้ดชุดนี้ขายเป็น template → ฟีเจอร์ที่มีคือที่เห็น
- ถ้าอยากได้ฟีเจอร์เพิ่ม สามารถพัฒนาต่อเองได้ หรือจ้างแยกต่างหาก

### ❌ แก้โค้ดที่ลูกค้าแก้เองแล้วพัง
- ถ้าคุณแก้ไฟล์ใน `app/Services/` หรือ `app/Repositories/` แล้วระบบพัง → ต้องแก้เอง
- แนะนำ: ใช้ Git เก็บเวอร์ชันก่อนแก้ไว้เสมอ จะได้ย้อนกลับได้

### ❌ Deploy ขึ้น cloud / VPS / server ขั้นสูง
- การติดตั้งบน XAMPP หรือ shared hosting พื้นฐาน → ช่วยได้
- แต่การ deploy บน AWS, DigitalOcean, Docker, Nginx → อยู่นอกขอบเขต
- เพราะแต่ละ environment มีรายละเอียดต่างกันมาก ต้องมีความรู้เฉพาะทาง

### ❌ สอนเขียนโปรแกรมแบบตัวต่อตัว
- อธิบายโค้ดในโปรเจคนี้ → ได้
- แต่สอน PHP ตั้งแต่เริ่มต้น, สอน SQL, สอน HTML/CSS → ไม่ได้
- แนะนำ: มีคอร์สออนไลน์ดีๆ เยอะมาก ลองหาเรียนควบคู่ไปด้วย

### ❌ ปรับแต่งหน้าตาเว็บตามดีไซน์ลูกค้า
- เช่น "ช่วยเปลี่ยนสีให้หน่อย", "ช่วยจัดหน้าใหม่"
- การปรับ CSS / layout เป็นงานที่ต้องทำเอง หรือจ้างแยก

### ❌ ซัพพอร์ตไม่มีกำหนดเวลา
- ซัพพอร์ตมีระยะเวลา (ดูหัวข้อที่ 5) ไม่ใช่ตลอดชีพ

## 🧠 4. เงื่อนไขสำคัญที่ลูกค้าควรรู้

### โค้ดนี้ออกแบบเพื่อ "เรียนรู้" และ "เดโม"
- ระบบทำงานได้จริง ใช้ได้จริง
- แต่ **ไม่ได้ออกแบบมาสำหรับผู้ใช้หลักพันคนพร้อมกัน**
- ถ้าจะนำไปใช้งานจริงจริง ควรเข้าใจโค้ดก่อนและปรับแต่งเพิ่มเติมตามความจำเป็น

### ไม่รับประกันการใช้งานระดับ Production
- ไม่รับประกันว่าจะทำงานได้ 100% ในทุก environment
- ไม่รับประกัน uptime, ความปลอดภัยระดับ enterprise, หรือ compliance ใดๆ
- เป็น template สำหรับเรียนรู้และต่อยอด ไม่ใช่ software สำเร็จรูประดับองค์กร

### อ่านเอกสารก่อนถาม
- ในโปรเจคมีเอกสารค่อนข้างละเอียดอยู่แล้ว:
  - 📄 `README.md` — ภาพรวมทั้งหมด, วิธีติดตั้ง, วิธีใช้
  - 📄 `docs/STUDY_GUIDE.md` — คู่มือศึกษาโค้ดเชิงลึก
  - 📄 `docs/FLOW.md` — Flow การทำงานทุก flow
  - 📄 `docs/ARCHITECTURE.md` — โครงสร้างระบบ
  - 📄 `docs/FAQ.md` — ปัญหาที่พบบ่อย + วิธีแก้
  - 📄 `docs/INSTALL.md` — ติดตั้งทีละขั้น (XAMPP / Shared Hosting)
  - 📄 `docs/DEPLOYMENT.md` — นำขึ้น production + security checklist
- **กรุณาลองอ่านเอกสารก่อนส่งคำถามมา** หลายคำถามมีคำตอบอยู่ในเอกสารแล้ว
- ถ้าอ่านแล้วยังไม่เข้าใจ → ถามมาได้เลย ไม่ต้องเกรงใจ

### ไม่มีการ Refund
- เนื่องจากเป็นสินค้าดิจิทัล (ไฟล์โค้ด) ที่ส่งมอบแล้ว → **ไม่สามารถขอคืนเงินได้**

## 🕒 5. ระยะเวลาและช่องทางการซัพพอร์ต

### ช่องทางติดต่อ

| ช่องทาง | รายละเอียด |
|---------|-----------|
| 💬 **Facebook** | DevMark สอนเขียนเว็บไซต์ |


### ระยะเวลาตอบกลับ
- ตอบภายใน **24–48 ชั่วโมง** (วันทำการ จันทร์–ศุกร์)
- วันเสาร์–อาทิตย์ / วันหยุด อาจตอบช้ากว่าปกติ
- **ไม่รับประกันว่าจะตอบได้ทันที** เพราะผู้ขายเป็นบุคคลคนเดียว ไม่ใช่ทีม support

### ระยะเวลาซัพพอร์ต
- ซัพพอร์ตหลังการซื้อ **30 วัน**
- ครอบคลุม: การติดตั้ง, การตั้งค่า, คำถามเกี่ยวกับโค้ดต้นฉบับ
- หลัง 30 วัน: ยังสามารถแจ้ง bug ของโค้ดต้นฉบับได้ แต่คำถามทั่วไปอาจไม่สามารถตอบได้ทุกข้อ

### วิธีถามให้ได้คำตอบเร็ว

ส่งข้อมูลเหล่านี้มาพร้อมคำถาม จะช่วยให้ตอบได้เร็วขึ้นมาก:

1. **อธิบายปัญหาสั้นๆ** — "กดยืมหนังสือแล้ว error" ดีกว่า "มันพัง"
2. **แนบ screenshot** — ถ้ามี error แสดงบนหน้าจอ ถ่ายรูปมาเลย
3. **บอกว่าทำอะไรก่อนจะพัง** — "ผมแก้ไฟล์ BorrowService.php บรรทัดที่ 50 แล้วมัน error"
4. **บอกว่าแก้โค้ดเองหรือยัง** — ถ้าแก้แล้ว บอกด้วยว่าแก้ไฟล์อะไรบ้าง

> ❌ **ข้อความที่ตอบยาก:** "ระบบใช้ไม่ได้ ช่วยดูหน่อย"
> ✅ **ข้อความที่ตอบง่าย:** "หลัง install เสร็จ login ไม่ได้ เจอ error นี้ [screenshot] ยังไม่ได้แก้โค้ดอะไรเลย"
