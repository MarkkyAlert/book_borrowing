# 📚 ระบบยืมคืนหนังสือ (Book Borrowing System)

---

## 1️⃣ ระบบนี้คืออะไร?

### ลองนึกภาพตามนะ...

สมมติคุณเปิดห้องสมุดเล็กๆ สักแห่ง มีหนังสือ 100 เล่ม มีสมาชิก 50 คน

ถ้าไม่มีระบบ คุณต้อง:
- จดสมุดว่าใครยืมอะไรไป
- จำว่าใครครบกำหนดส่งวันไหน
- คำนวณค่าปรับเอง
- ไม่มีทางรู้ว่า "หนังสือเล่มนี้ว่างไหม" ถ้าไม่เปิดสมุดดู

**ระบบนี้คือ "ห้องสมุดออนไลน์" ที่ทำทุกอย่างให้คุณอัตโนมัติ**

มันช่วย:
- ✅ จัดการหนังสือ (เพิ่ม, แก้ไข, ลบ, ค้นหา)
- ✅ จัดการสมาชิก (สมัคร, ดูประวัติ)
- ✅ ยืม-คืนหนังสือ (คำนวณค่าปรับอัตโนมัติ)
- ✅ จองหนังสือ (ถ้าอยากมารับทีหลัง)
- ✅ พิมพ์รายงาน (สรุปยอดยืม, สถิติ, ค่าปรับ)
- ✅ บัตรสมาชิก (พิมพ์ได้เลย)

### เหมาะกับใคร?

| ✅ เหมาะ | ❌ ไม่เหมาะ |
|---------|------------|
| ห้องสมุดโรงเรียน / ชุมชน | ห้องสมุดแห่งชาติ (หนังสือเป็นล้าน) |
| ร้านเช่าหนังสือเล็กๆ | ระบบที่ต้องรองรับคนพันคนพร้อมกัน |
| โปรเจคส่งอาจารย์ | ระบบที่ต้อง online 24/7 ไม่มีวันล่ม |
| เรียนรู้ PHP / ฝึก backend | Production ระดับองค์กรใหญ่ |
| เดโมให้ลูกค้าดู / ขาย template | ระบบที่ต้องผ่าน security audit ระดับสูง |

### พูดง่ายๆ

ระบบนี้เหมือน **"ร้านอาหารขนาดเล็กที่บริหารงานด้วยคนไม่กี่คน"**
— ไม่ใช่โรงแรม 5 ดาว แต่ทำงานได้จริง ใช้งานง่าย เพียงพอสำหรับกิจการเล็กๆ

## 2️⃣ ภาพรวมการทำงานของระบบ

### ระบบทำงานยังไง? (ฉบับเข้าใจง่าย)

ลองนึกภาพ **ร้านอาหาร** แล้วเปรียบเทียบ:

```
👤 ลูกค้าสั่งอาหาร      →   ผู้ใช้กดปุ่มบนเว็บ
📋 พนักงานรับออเดอร์      →   Controller (ไฟล์ .php ที่หน้าเว็บ)
👨‍🍳 พ่อครัวทำอาหาร        →   Service (ไฟล์ใน app/Services/)
🏪 คลังวัตถุดิบ           →   Repository (ไฟล์ใน app/Repositories/)
🗄️ ตู้เย็นเก็บของ         →   Database (MySQL)
```

### ตัวอย่างจริง: "สมาชิกยืมหนังสือ"

```
1. 👤 Staff กดปุ่ม "บันทึกการยืม" บนหน้าเว็บ
         ↓
2. 📋 ไฟล์ admin/borrow_form.php รับข้อมูล
   (ตรวจว่า Staff จริงไหม? ข้อมูลครบไหม?)
         ↓
3. 👨‍🍳 BorrowService ทำงาน:
   - ตรวจว่าสมาชิกยืมเกินโควต้าไหม (สูงสุด 3 เล่ม)
   - ตรวจว่าหนังสือยังว่างไหม
   - หัก stock หนังสือ
   - สร้างบันทึกการยืม
         ↓
4. 🏪 BorrowRepository + BookRepository
   - บันทึกข้อมูลลง database จริงๆ
         ↓
5. ✅ แสดงผล "ยืมสำเร็จ!"
```

### ทำไมต้องแยกเป็นชั้นๆ?

คำตอบง่ายๆ: **เพื่อให้แก้ไขง่าย + ไม่พัง**

- ถ้าอยากเปลี่ยน "ยืมได้ 5 เล่ม แทน 3 เล่ม" → แก้แค่ config
- ถ้าอยากเปลี่ยนหน้าตาเว็บ → แก้แค่ไฟล์ใน admin/
- ถ้าอยากเปลี่ยนวิธีคำนวณค่าปรับ → แก้แค่ BorrowService

**ไม่ต้องแก้ทุกไฟล์** เพราะแต่ละชั้นทำงานแยกกัน

### สรุปคำศัพท์สำคัญ

| คำศัพท์ | แปลว่า | เปรียบเทียบ |
|---------|--------|-------------|
| **Controller** | ไฟล์ .php ที่รับ request | พนักงานรับออเดอร์ |
| **Service** | ไฟล์ที่มีกฎธุรกิจ | พ่อครัว (คิดว่าทำอะไรได้/ไม่ได้) |
| **Repository** | ไฟล์ที่คุยกับ database | คลังวัตถุดิบ (หยิบของ/เก็บของ) |
| **Database** | ฐานข้อมูล MySQL | ตู้เย็น (เก็บข้อมูลทั้งหมด) |
| **Session** | ข้อมูลชั่วคราวของ user | บัตรคิว (ระบบจำได้ว่าคุณคือใคร) |
| **CSRF Token** | รหัสป้องกันการปลอมแปลง | ลายเซ็นยืนยันตัวตน |
| **Rate Limit** | จำกัดจำนวนครั้งที่ทำได้ | ป้อม รปภ. (ถ้าลองผิดมาก ไม่ให้เข้า) |

## 4️⃣ Flow สำคัญของระบบ (Step by Step)

### 🔐 Flow 1: Login (เข้าสู่ระบบ)

```
Step 1 → ผู้ใช้เปิดหน้า login.php
         (ระบบสร้าง CSRF token ให้อัตโนมัติ)

Step 2 → กรอก email + password แล้วกด "เข้าสู่ระบบ"
         (ข้อมูลถูกส่งไปที่ server)

Step 3 → ระบบตรวจ "กรอกครบไหม?"
         ถ้าไม่ → แสดง "กรุณากรอกอีเมล/รหัสผ่าน"

Step 4 → ระบบตรวจ "ลองผิดมาเกิน 5 ครั้งไหม?"
         ถ้าใช่ → แสดง "รอ 15 นาที" (ป้องกันคนเดารหัส)

Step 5 → ระบบเช็ค email + password กับ database
         ถ้าไม่ตรง → แสดง "อีเมลหรือรหัสผ่านไม่ถูกต้อง"
         (ไม่บอกว่าอะไรผิด → ป้องกันคนมาเดา email)

Step 6 → ✅ สำเร็จ!
         - สร้าง session ใหม่ (จำว่าคุณเป็นใคร)
         - ถ้าเป็น admin/staff → ไปหน้า admin
         - ถ้าเป็น member → ไปหน้าแรก
```

**ทำไมต้องมี Rate Limit?**
เพราะถ้าไม่มี คนร้ายสามารถลองรหัสผ่านล้านๆ ครั้งจนเจอ ระบบจึงล็อคไว้ว่า "ผิด 5 ครั้ง = รอ 15 นาที"

---

### 📝 Flow 2: Register (สมัครสมาชิก)

```
Step 1 → ผู้ใช้เปิดหน้า register.php

Step 2 → กรอกข้อมูล: ชื่อ, email, เบอร์โทร, รหัสผ่าน, ยืนยันรหัสผ่าน

Step 3 → ระบบตรวจข้อมูล:
         - ชื่อว่างไหม?
         - email ถูกรูปแบบไหม?
         - email ซ้ำกับคนอื่นไหม?
         - รหัสผ่านยาวพอไหม? (อย่างน้อย 6 ตัว)
         - ยืนยันรหัสผ่านตรงกันไหม?
         ถ้าไม่ผ่าน → แสดง error ทั้งหมด

Step 4 → ✅ สำเร็จ!
         - เข้ารหัสรหัสผ่าน (ใครแฮค database ก็อ่านไม่ได้)
         - บันทึกลง database (เป็น role "member")
         - ไปหน้า login + แสดง "สมัครสำเร็จ กรุณาเข้าสู่ระบบ"
```

**ทำไมต้องเข้ารหัสรหัสผ่าน?**
เพราะถ้าเก็บรหัสผ่านแบบตัวอักษรปกติ ถ้ามีคนเจาะ database ก็เห็นรหัสผ่านทุกคน ระบบนี้ใช้ `bcrypt` ซึ่งเป็นมาตรฐานระดับสากล

---

### 📖 Flow 3: ยืมหนังสือ (Create Borrow)

```
Step 1 → Staff เข้าหน้า admin/borrow_form.php

Step 2 → เลือกสมาชิก + เลือกหนังสือ (ได้หลายเล่ม) + กำหนดวันยืม

Step 3 → กด "บันทึกการยืม"

Step 4 → ระบบตรวจ:
         - สมาชิกคนนี้ยืมเกิน 3 เล่มหรือยัง?
         - หนังสือแต่ละเล่มยังว่างไหม?
         - ยืมเล่มเดิมซ้ำหรือเปล่า?

Step 5 → ✅ สำเร็จ!
         - หัก stock หนังสือ (available ลด 1)
         - สร้างบันทึกการยืม (status = "กำลังยืม")
         - คำนวณวันกำหนดคืน

⚠️ ถ้ามีคน 2 คน กดยืมสำเนาสุดท้ายพร้อมกัน:
   → ระบบจะ "ล็อค" ข้อมูล → คนแรกได้ → คนที่สอง error
   (เหมือนซื้อตั๋วหนังที่เหลือนั่งสุดท้าย)
```

---

### 📕 Flow 4: คืนหนังสือ (Return Book)

```
Step 1 → Staff เข้าหน้า admin/borrows.php

Step 2 → หารายการที่ต้องคืน → กดปุ่ม "คืนหนังสือ"

Step 3 → ระบบทำอัตโนมัติ:
         - เช็คว่าเกินกำหนดไหม
```

## 5️⃣ การติดตั้ง (สำหรับมือใหม่จริงๆ)

### สิ่งที่ต้องมี

| สิ่งที่ต้องมี | ทำไมต้องมี | แนะนำ |
|--------------|-----------|-------|
| **XAMPP** | ได้ PHP + MySQL + Apache มาครบในตัว | XAMPP 8.2+ |
| **Web Browser** | เปิดเว็บดูผลลัพธ์ | Chrome / Firefox |
| **Text Editor** | ดูและแก้โค้ด (ถ้าจำเป็น) | VS Code (ฟรี) |

> 💡 **PHP version:** ระบบนี้ใช้ PHP 8.0 ขึ้นไป (เพราะใช้ `str_starts_with`, `match`, typed properties)

### ขั้นตอนติดตั้ง (ทำทีละขั้น)

#### ขั้นที่ 1: ติดตั้ง XAMPP

1. ดาวน์โหลด XAMPP จาก https://www.apachefriends.org/
2. ติดตั้งตามปกติ (Next → Next → Finish)
3. เปิด XAMPP Control Panel
4. กด **Start** ที่ **Apache** → เห็น port 80, 443 สีเขียว
5. กด **Start** ที่ **MySQL** → เห็น port 3306 สีเขียว

> ❌ **ถ้า Apache ไม่ Start:**
> แปลว่า port 80 ถูกโปรแกรมอื่นใช้อยู่ (เช่น Skype, IIS)
> วิธีแก้: ปิดโปรแกรมที่ใช้ port 80 แล้วลองใหม่

> ❌ **ถ้า MySQL ไม่ Start:**
> แปลว่ามี MySQL ตัวอื่นรันอยู่แล้ว
> วิธีแก้: ปิด MySQL ตัวอื่นก่อน หรือเปลี่ยน port

#### ขั้นที่ 2: วางโค้ด

1. ไปที่โฟลเดอร์ `C:\xampp\htdocs\`
2. วางโฟลเดอร์ `book_borrowing` ลงไป
3. ผลลัพธ์ควรเป็น: `C:\xampp\htdocs\book_borrowing\index.php`

> ❌ **ถ้าเปิดเว็บแล้วเห็น "Object not found":**
> แปลว่าวางโฟลเดอร์ผิดที่ ตรวจว่า path ถูกไหม

#### ขั้นที่ 3: ตั้งค่า .env

1. ดูไฟล์ `.env.example` ในโฟลเดอร์โปรเจค
2. สร้างไฟล์ `.env` (คัดลอกจาก `.env.example`)
3. เปิด `.env` แล้วตรวจค่าเหล่านี้:

```env
DB_HOST=localhost
DB_NAME=book_borrowing
DB_USER=root
DB_PASS=
APP_URL=http://localhost/book_borrowing
```

> 💡 **XAMPP default:** user = `root`, password = ว่าง (ไม่ต้องใส่)
> ถ้าใช้ hosting อื่น ต้องเปลี่ยน user + password ให้ตรง

#### ขั้นที่ 4: ติดตั้ง database

1. เปิด Browser ไปที่: `http://localhost/book_borrowing/install.php`
2. ใส่ email admin (หรือใช้ค่าเดิม `admin@library.com`)
3. ใส่รหัสผ่าน admin (อย่างน้อย 6 ตัว หรือเว้นว่างให้ระบบสร้างให้)
4. กด **"เริ่มติดตั้ง"**
5. ✅ เห็นข้อความ "ติดตั้งระบบเรียบร้อยแล้ว!"

> **⚠️ สำคัญ:** จดรหัสผ่าน admin ไว้! ถ้าระบบสร้างให้ จะแสดงบนหน้าจอแค่ครั้งเดียว

> ❌ **ถ้าเห็น "Connection refused":**
> แปลว่า MySQL ไม่ได้รัน → กลับไปเปิดใน XAMPP Control Panel

> ❌ **ถ้าเห็น "Access denied for user":**
> แปลว่า user/password ใน `.env` ไม่ตรง → แก้ไฟล์ `.env`

#### ขั้นที่ 5: เข้าใช้งาน!

1. ไปที่ `http://localhost/book_borrowing/`
2. กด "เข้าสู่ระบบ"
3. ใส่ email + password ที่ตั้งไว้ตอนติดตั้ง
4. 🎉 เข้าสู่ระบบสำเร็จ!

> 💡 **ถ้าลืมรหัสผ่าน admin:**
> ใช้หน้า "ลืมรหัสผ่าน" หรือรันคำสั่ง SQL โดยตรงใน phpMyAdmin

## 6️⃣ การตั้งค่า (Config)

### ไฟล์ config อยู่ตรงไหน?

ค่าตั้งค่าอยู่ใน **ไฟล์ `.env`** ที่โฟลเดอร์หลักของโปรเจค

> 💡 `.env` คืออะไร?
> คือไฟล์ข้อความธรรมดาที่เก็บค่าตั้งค่า แบบ `ชื่อ=ค่า` เปิดด้วย Notepad ก็ได้

### ✅ ค่าที่ "ควรแก้" ตามต้องการ

```env
# ชื่อระบบ (แสดงบนหัวเว็บ)
APP_NAME="ห้องสมุดโรงเรียนสวนสวย"

# URL ของเว็บ (ถ้าเปลี่ยน folder หรือขึ้น hosting ต้องแก้)
APP_URL=http://localhost/book_borrowing

# จำนวนวันยืมเริ่มต้น (ตอนนี้ 7 วัน)
DEFAULT_BORROW_DAYS=7

# ยืมได้สูงสุดกี่เล่มต่อคน (ตอนนี้ 3 เล่ม)
MAX_BORROW_BOOKS=3

# ค่าปรับต่อวันที่เกิน (ตอนนี้ 10 บาท)
FINE_PER_DAY=10

# เปิด/ปิดโหมด debug (ตอนพัฒนาเปิด, ตอนใช้จริงปิด)
APP_DEBUG=false
```

### ⚠️ ค่าที่ "แก้ได้แต่ต้องระวัง"

```env
# ข้อมูลเชื่อมต่อ database (แก้ผิดเข้า DB ไม่ได้)
DB_HOST=localhost
DB_NAME=book_borrowing
DB_USER=root
DB_PASS=

# อายุ session (วินาที) — ตั้งสั้นไป user ถูก logout บ่อย
SESSION_LIFETIME=3600
```

### 🔴 ค่าที่ "ไม่ควรแก้" (ถ้าไม่เข้าใจ)

```env
# ป้องกัน brute force — แก้เยอะ = ระบบไม่ปลอดภัย
RATE_LIMIT_MAX_ATTEMPTS=5
RATE_LIMIT_WINDOW_MINUTES=15

# ความยาวรหัสผ่านขั้นต่ำ — แก้น้อยเกิน = ไม่ปลอดภัย
MIN_PASSWORD_LENGTH=6
```

### ตั้งค่าผ่านหน้าเว็บ (ง่ายกว่า)

Admin สามารถตั้งค่าบางอย่างผ่านหน้าเว็บได้ที่ **Admin → ตั้งค่าระบบ**:
- ชื่อหน่วยงาน (แสดงบนบัตรสมาชิก)
- สีบัตรสมาชิก (สีหลัก + สีรอง)

## 🔟 คำถามที่มือใหม่ถามบ่อย (FAQ)

### ❓ ใช้ PHP เวอร์ชันอะไร?

**PHP 8.0 ขึ้นไป** (แนะนำ 8.1 หรือ 8.2)
ถ้าใช้ XAMPP 8.2 ก็พร้อมใช้เลย ไม่ต้องตั้งค่าเพิ่ม

### ❓ ใช้ shared hosting ได้ไหม?

**ได้!** ถ้า hosting มี:
- PHP 8.0+
- MySQL 5.7+ หรือ MariaDB 10.3+
- Apache + mod_rewrite

วิธีทำ:
1. Upload โฟลเดอร์ทั้งหมดไปที่ `public_html/book_borrowing/`
2. แก้ `.env` ให้ตรงกับ database ของ hosting
3. เปิด `http://yourdomain.com/book_borrowing/install.php`
4. ติดตั้งเสร็จ → ลบ `install.php` ทิ้ง

### ❓ ถ้าแก้โค้ดแล้วพัง ทำยังไง?

1. **เปิด browser ดู error message** — ถ้า `APP_DEBUG=true` ใน `.env` จะเห็น error ชัดเจน
2. **ดูไฟล์ log** — อยู่ในโฟลเดอร์ `logs/`
3. **เอาโค้ดเก่ากลับ** — ถ้าใช้ Git พิมพ์ `git checkout -- ชื่อไฟล์`
4. **ถ้าพังหมด** — ลบ database ใน phpMyAdmin แล้วรัน `install.php` ใหม่

### ❓ เพิ่มฟีเจอร์เองได้ไหม?

**ได้** แต่ต้องเข้าใจโครงสร้างก่อน:

| อยากทำ | ต้องแก้/เพิ่มตรงไหน |
|--------|-------------------|
| เพิ่มหน้าเว็บใหม่ | สร้างไฟล์ .php ใหม่ + require bootstrap.php |
| เพิ่มตารางใน DB | เพิ่มใน `database/schema.sql` + สร้าง Repository |
| เพิ่ม business logic | สร้างไฟล์ใหม่ใน `app/Services/` |
| เพิ่มเมนู admin | แก้ `admin/header.php` |

> 💡 **กฎทอง:** อย่าแก้ไฟล์ Service/Repository เดิม ถ้าไม่แน่ใจ ให้สร้างไฟล์ใหม่แทน

### ❓ ทำไมไม่ใช้ Laravel?

ระบบนี้ตั้งใจเขียนด้วย **PHP ล้วน** เพราะ:
- **เรียนรู้ง่ายกว่า** — เห็นการทำงานจริงของ PHP ไม่มี "เวทมนตร์" ซ่อนอยู่
- **Deploy ง่าย** — แค่ copy ไฟล์ไปวาง ไม่ต้อง `composer install`
- **เหมาะสอน** — เข้าใจ Controller/Service/Repository โดยไม่ต้องเรียน framework ก่อน

### ❓ Login เข้าแล้วไม่เจอหน้า admin?

ตรวจสอบ 2 อย่าง:
1. **บัญชีของคุณเป็น role อะไร?** — ถ้าเป็น `member` จะไม่เห็น admin
2. **APP_URL ใน .env ตรงไหม?** — ถ้า URL ผิด redirect จะพลาด

### ❓ Database หาย / ข้อมูลหาย ทำยังไง?

1. ถ้ายังเข้า phpMyAdmin ได้ → ลองเปิดดูว่า database `book_borrowing` ยังอยู่ไหม
2. ถ้า database หาย → รัน `install.php` ใหม่ (ได้ database เปล่า + ข้อมูลตัวอย่าง)
3. ถ้าอยาก restore → ต้อง import จาก backup SQL ที่เคย export ไว้

> 💡 **แนะนำ:** Export database สำรองไว้เป็นระยะ ผ่าน phpMyAdmin → Export → SQL

### ❓ รูปปกหนังสือหายหมด?

รูปปกเก็บในโฟลเดอร์ `uploads/covers/`
ถ้าลบโฟลเดอร์นี้ → รูปหายแต่ระบบไม่พัง (แสดงเป็นรูปเปล่าแทน)

### ❓ ลืมรหัสผ่าน Admin ทำยังไง?

วิธีที่ 1: ใช้หน้า "ลืมรหัสผ่าน" (ถ้าตั้งค่า email ไว้)

วิธีที่ 2: แก้ตรงใน database
1. เปิด phpMyAdmin → `http://localhost/phpmyadmin`
2. เลือก database `book_borrowing`
3. เปิดตาราง `users`
4. หา row ที่ role = admin
5. คัดลอก hash นี้ไปวางในช่อง password:
   `$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi`
   (นี่คือ hash ของคำว่า "password")
6. Login ด้วยรหัสผ่าน `password` แล้วเปลี่ยนทันที!
