1. เกี่ยวกับ License นี้
------------------------------------------------------------

เอกสารนี้เป็นข้อตกลงระหว่าง "ผู้ขาย" และ "ผู้ซื้อ"
เกี่ยวกับสิทธิ์ในการใช้งานชุดโค้ด Template นี้

License นี้เป็นแบบ "Single User"
หมายความว่า: 1 การซื้อ = 1 ผู้ใช้งาน
ผู้ซื้อ 1 คน สามารถใช้โค้ดนี้ในโปรเจกต์ของตนเองได้
แต่ไม่สามารถส่งต่อให้ผู้อื่นใช้งานได้

2. สิทธิ์ที่อนุญาต (สิ่งที่คุณทำได้)
------------------------------------------------------------

ผู้ซื้อได้รับอนุญาตให้:

  [/] ใช้โค้ดเพื่อเรียนรู้ ศึกษา และทำความเข้าใจ
      การพัฒนาระบบ Backend

  [/] แก้ไข ปรับแต่ง ต่อยอดโค้ดเพื่อใช้งานส่วนตัว
      หรือในโปรเจกต์ของตนเอง

  [/] ใช้ในโปรเจกต์เชิงพาณิชย์ขนาดเล็ก
      เช่น ระบบห้องสมุดโรงเรียน ร้านเช่าหนังสือ

  [/] ใช้เป็น demo ประกอบการเสนองาน
      หรือแสดงใน portfolio ของตนเอง

  [/] ใช้เป็นส่วนหนึ่งของงานที่ส่งอาจารย์
      หรือ project จบการศึกษา

  [/] นำไปปรับแต่งเป็น product ใหม่ของตนเอง
      แล้วขายเป็น "บริการ" หรือ "ระบบสำเร็จรูป"
      ให้ลูกค้าของตนเอง (ไม่ใช่ขายเป็นโค้ด template)

  [/] ใช้โค้ดนี้ซ้ำในหลายโปรเจกต์ของตนเอง
      (ไม่จำกัดจำนวนโปรเจกต์ ตราบใดที่เป็นผู้ซื้อคนเดิม)

3. สิ่งที่ไม่อนุญาต (สิ่งที่คุณทำไม่ได้)
------------------------------------------------------------

ผู้ซื้อไม่ได้รับอนุญาตให้:

  [x] นำโค้ดไปขายต่อ ทั้งก้อนหรือบางส่วน
      ในรูปแบบ template, source code, boilerplate
      หรือสินค้าดิจิทัลที่ลูกค้าได้รับซอร์สโค้ดไป

  [x] แจกจ่ายโค้ดให้ผู้อื่น ไม่ว่าจะฟรีหรือมีค่าใช้จ่าย
      รวมถึงการส่งไฟล์ให้เพื่อน เพื่อนร่วมงาน หรือลูกค้า
      ในรูปแบบซอร์สโค้ด

  [x] อัปโหลดโค้ดขึ้น repository สาธารณะ
      เช่น GitHub, GitLab, Bitbucket แบบ public
      (ใช้ private repository ได้)

  [x] อ้างว่าเป็นผู้สร้างหรือเจ้าของโค้ดต้นฉบับ

  [x] นำโค้ดไปใช้เป็นฐานสำหรับสร้าง template
      ที่ขายแข่งกับผู้ขายโดยตรง

  [x] ลบหรือแก้ไขข้อมูล license นี้
      ออกจากชุดโค้ดที่ได้รับ

4. ตัวอย่างให้เข้าใจชัดเจน
------------------------------------------------------------

เพื่อไม่ให้เกิดความสับสน:

  ทำได้:
  - ซื้อโค้ด -> แก้ไข -> ทำเป็นระบบให้ร้านค้า -> ขาย "บริการ"
  - ซื้อโค้ด -> แก้ไข -> ส่งเป็น project จบ
  - ซื้อโค้ด -> แก้ไข -> ใช้ในร้านของตัวเอง
  - ซื้อโค้ด -> ศึกษาโค้ด -> เรียนรู้ -> เอาแนวคิดไปเขียนใหม่

  ทำไม่ได้:
  - ซื้อโค้ด -> ขายซอร์สโค้ดต่อบน Shopee / Facebook
  - ซื้อโค้ด -> ส่งไฟล์ให้เพื่อนใช้ฟรี
  - ซื้อโค้ด -> อัปโหลดขึ้น GitHub แบบ public
  - ซื้อโค้ด -> เปลี่ยนชื่อ -> ขายเป็น template ของตัวเอง


------------------------------------------------------------
5. ขอบเขตความรับผิดชอบ
------------------------------------------------------------

โค้ดชุดนี้ให้มา "ตามสภาพ" (as-is)

ผู้ขาย:
  - จัดส่งโค้ดที่ทำงานได้ตามที่ระบุไว้ในเอกสารประกอบ
  - ให้เอกสารและคู่มือประกอบตามที่ระบุ
  - ให้การซัพพอร์ตตามเงื่อนไขใน SUPPORT.md

ผู้ขายไม่รับประกัน:
  - ว่าโค้ดจะเหมาะสมกับทุกกรณีใช้งาน
  - ว่าโค้ดจะปราศจากข้อผิดพลาดทุกประการ
  - ว่าโค้ดจะทำงานได้ในทุก environment
  - ผลลัพธ์ทางธุรกิจจากการนำโค้ดไปใช้งาน

ผู้ซื้อเป็นผู้รับผิดชอบ:
  - การนำโค้ดไปใช้งาน
  - การ deploy ขึ้น server
  - การดูแลรักษาระบบ
  - การสำรองข้อมูล
  - ความปลอดภัยของ server ที่ติดตั้ง
  - ความเสียหายที่เกิดจากการใช้งาน
    หรือการแก้ไขโค้ดโดยผู้ซื้อเอง
